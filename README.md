# Model Manager

A C++ program to manage machine learning models. Users can interactively **add**, **remove**, **update**, **find**, and **list** models via a console menu.

## Features
- Add a new model with name, version, accuracy, creation date, and description.
- Remove a model by name.
- Update a model's version, accuracy, or description.
- Find and display a model by name.
- List all models in the system.
